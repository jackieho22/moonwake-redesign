# Moonwake Coffee Roasters — Home Page Redesign (Concept)

A concept redesign of the Moonwake Coffee Roasters home page, made for my portfolio.
**Not affiliated with or endorsed by Moonwake Coffee Roasters.**

The goal: make the home page friendlier to first-time coffee buyers and to people who want to
understand who Moonwake is, with a feel that is elegant, clean and transparent.

## Highlights

- **Ask a Barista quiz** — five quick questions that recommend three coffees, with a carousel
  where each coffee's tasting-note fruit fans out from behind the bag.
- **This Month's Roasts** — cards that reveal the farmers and the tasting-note fruit on hover,
  over a wave texture drawn from the logo's "wake" lines.
- **Shop Our Series** — photo bars that grow open on hover with a playful spring.
- Header dropdowns, crossfading Enhance Your Brew tiles and a consistent spacing system.

## Stack

Vite · React · MUI · Motion

## Run it locally

```bash
npm install
npm run dev      # development server
npm run build    # production build into dist/
npm run preview  # serve the production build
```

Designed for desktop (1280px and wider).
